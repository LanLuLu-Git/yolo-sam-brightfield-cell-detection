# YOLO + SAM Brightfield Cell Detection and Segmentation

Detection and segmentation of cells in brightfield microscopy images, combining a modified
[Ultralytics YOLO](https://github.com/ultralytics/ultralytics) detector with
[Segment Anything (SAM)](https://github.com/facebookresearch/segment-anything).

## Algorithm pipeline

1. **Detection** — a YOLO model, extended with custom modules under `ultralytics/change_model/`
   (FEB, PFAE, Di_SpAM, FRCAM, WTFD, Restormer, CAFM_184), predicts a bounding box and class label
   for every cell in the image.
2. **Segmentation** — each detected box is passed to SAM, which produces a set of candidate masks.
   The highest-confidence mask is kept, and the cell centroid is computed from it.
3. **Post-processing** — optionally localizes a reference microsphere ("Sphere_Probe") by template
   matching, excludes detections near the microsphere center, suppresses duplicate detections, and
   then renders dashed contours / centroid cross markers / a scale bar onto the result image.
4. **Output** — the annotated image is saved, and (optionally) a CSV of per-cell coordinates
   relative to the probe is written.

## Repository layout

```
├── XTCpredictV21.py          # main batch prediction script (YOLO + SAM)
├── jpkautorun.py             # single-image auto-run loop (watches one input path)
├── version_info.py           # print Python / library version info
├── ultralytics-main/         # modified ultralytics source (change_model/ improvements)
├── segment-anything-main/    # only the SAM checkpoint lives here (source comes from pip)
├── requirements.txt          # pip dependencies
├── environment.yml           # conda environment
└── .gitignore
```

## Installation

Conda (recommended, reproduces the original environment):

```bash
conda env create -f environment.yml
conda activate YOLOSAM
```

Or pip:

```bash
pip install -r requirements.txt
```

`requirements.txt` declares `ultralytics` and `segment-anything`. This project modifies the
ultralytics source (adds `ultralytics/change_model/`), so the scripts import the vendored copy in
`ultralytics-main/` rather than the pip-installed package.

## Model weights (not included in this repository)

All `*.pt` / `*.pth` files are excluded via `.gitignore`. Download or retrain them yourself:

- **SAM checkpoint** `sam_vit_h_4b8939.pth` (~2.4 GB):
  ```bash
  wget https://dl.fbaipublicfiles.com/segment_anything/sam_vit_h_4b8939.pth \
       -P segment-anything-main/models/
  ```
- **Official YOLO pretrained weights** (yolo11n/s/m.pt, yolov8n.pt): downloaded automatically by
  `pip install ultralytics`, or obtained from the ultralytics releases.
- **Trained weights** (`runs/**/weights/best.pt`, `ultralytics-main/weights/best.pt`, …): these are
  training outputs and must be regenerated by training.

## Usage

All paths and parameters are centralized in the `XTCPredictConfig` class at the top of each script.

1. Open `XTCpredictV21.py` (or `jpkautorun.py`) and edit the `XTCPredictConfig.__init__` values:
   - `input_image_dir` / `input_image_path` — where the input images are.
   - `result_image_dir` / `result_data_dir` — where results are written.
   - `yolo_weights_path` — path to a trained YOLO checkpoint (`best.pt`).
   - `sam_checkpoint` — path to the SAM checkpoint.
2. Batch mode (process every image in a directory):
   ```bash
   python XTCpredictV21.py
   ```
3. Auto-run mode (watch a single image path in a loop, converting tif→jpg and processing on arrival):
   ```bash
   python jpkautorun.py
   ```

## Notes

- Several scripts still contain machine-specific absolute paths (e.g.
  `D:/Project/YOLOwithSAM/ultralytics-main` in `XTCpredictV21.py` and `jpkautorun.py`, and the
  `runs/.../best.pt` weight paths). Adjust them to your own directory layout before running on
  another machine.
