## **The easiest one-click official YOLO11 project workflow**🚀️

No environment setup needed, one-click training.

---

### Step 1: Open the console and enter

```python
cd ultralytics-8.3.27
```

### Step 2: Training command

```python
python train_11.py --cfg ultralytics/cfg/models/11/yolo11.yaml
```
```
python train_11.py --cfg ultralytics/cfg/models/11/yolo11_s.yaml --scales m  (n s m l x)
```
Example command:
![](https://pica.zhimg.com/80/v2-ee88bf6837bbe3570ade3c2a38ca2b80_720w.png)

Training will start.

YOLO11 training output looks like:

![](https://picx.zhimg.com/80/v2-c71fc2fd56d2a935cb5a4b9712504d97_720w.png)

To stop training, press Ctrl+C.

To monitor GPU memory usage: watch -n 1 nvidia-smi

Academic mirror for faster access: source /etc/network_turbo

The runs/ directory contains the training output.

### Step 3: Inference command

```python
python predict.py
```

---

### About the dataset

By default, the coco128 dataset is used for validation; you can point it to your own dataset for training.

Modify the `data='coco128.yaml'` parameter in train_11.py to your own dataset's yaml file.

Refer to the ultralytics/cfg/datasets/ directory for other datasets.

### Training parameters
Modify the dataset path and network model weight path.

--cfg is followed by the network config file.

--weights is followed by the official weight name, e.g. yolo11n.pt
